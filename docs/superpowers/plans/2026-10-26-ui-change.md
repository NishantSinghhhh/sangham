# Sangam dashboard implementation plan

**Goal:** Make the payment demonstration clear, distinctive, accessible, and usable on desktop and mobile.

**Architecture:** Keep vanilla TypeScript, native HTML, CSS, existing API routes, and polling. Use Interface Design as the design lead and Vercel Web Interface Guidelines for review. No new runtime dependencies.

## Design brief

- Audience: hackathon presenter and viewers examining how USDC collection relates to an INR payout.
- Domain: treasury ledger, settlement corridor, receipt, railway ticket, payer, merchant, testnet.
- Palette: ledger-paper ivory, forest ink, sage, USDC blue, muted brass for simulation notices. Green is the primary action colour; amber/red distinguish held/failed states.
- Signature: a two-sided USDC-to-INR corridor, with a clearly separate settlement agent between the two accounts. Echo its route line in the logo, navigation, pipeline, and ledger progress.
- Hierarchy: overview metrics, active payment corridor, settlement ledger, then merchant and technical invoice detail. Sidebar links navigate real sections.
- Typography: locally installed/fallback sans-serif with serif display headings; tabular figures for financial amounts. No external font dependency.
- Depth: restrained tonal surfaces, fine borders, a single dark corridor panel. Four-pixel spacing rhythm, 8/12/20px radius scale.
- Alternatives considered: a large marketing landing page would bury the demo; a dense trading terminal would overstate functionality. Choose an approachable operational dashboard.
- Preserve all underlying payment endpoints. Explicitly label mocks, testnet, skipped verification, and payout requests. Never invent balances, trends, or real bank completion.

## Review focus

- No payments: useful empty state, not fabricated activity.
- Mock payouts: explicit demo amounts; no claim of bank confirmation.
- API errors: retain previous data with a stale-data warning; retry on refresh/poll.
- Long names and IDs: wrap within panels; ledger alone may scroll horizontally.
- CSV cells: escape delimiters/quotes and neutralise spreadsheet formulas in untrusted text.
